# Cassie · iPhone 语音助手开发预览版

## 0.5.0 端侧 AI（已推送并通过构建）

接入 Apple FoundationModels（iOS 26 + Apple Intelligence，iPhone 15 Pro 及以上）。模型完全跑在手机神经引擎上：**免费、无 API 密钥、无账号、文字不离开设备**，与既有隐私路线一致。

| 能力 | 行为 |
| --- | --- |
| 自由问答 | 首页输入/语音说的话若不匹配任何本机命令，交给端侧模型回答。上下文只带：当前时间、今天的 Dayplan 方案或清单、已完成事项、下一节课、最近3条待整理记录。流式显示，可播报。指令要求模型只依据上下文、不知道就说不知道、不编造课表成绩地点、不提供医疗法律投资建议。 |
| 端侧 AI 清单提取 | 清单草稿页新增"用端侧 AI 提取"：结构化输出任务名/用时/开始/截止/地点线索，比规则提取更懂复杂表述。结果同样逐项核对、地点仍需在编辑页地图确认后才能导入。 |
| 不可用降级 | iOS < 26、机型不支持、未开启 Apple Intelligence 或系统语言不支持时，页面显示具体原因，自动回退到规则提取和原命令提示，不会静默失败。 |

构建改动：GitHub Actions 工作流新增 setup-xcode 步骤选最新稳定 Xcode（iOS 26 SDK）。命令路由仍是本机规则优先，AI 只处理规则不认识的开放问题。

## 0.4.0 自动提醒（已推送并通过构建）

全部为本机通知（UNUserNotificationCenter），不联网、不上传：

| 提醒 | 触发规则 |
| --- | --- |
| 任务出发提醒 | 按已生成的 Dayplan 方案，每段出发时间发通知（含目的地与通勤时长）。生成、重排方案或勾选完成后自动重新安排；清单改动后旧提醒作废，需重新生成。 |
| 作业截止提醒 | 方案中带截止时间的任务，在截止前（默认60分钟，可调10–240）提醒。截图待办里识别出的"截止"时间同样生效。 |
| 上课出发提醒 | 按所选课表的上课时间倒推：默认走路15分钟＋缓冲10分钟，均可调；只排未来1/2/3/7天（默认3天）内的课。换教室同样适用；不读取实时位置，走路分钟数需按最远教学楼自行调整。 |
| 睡觉线提醒 | 每日固定时间（默认23:30）重复提醒，可改时间或关闭。 |

首页新增"自动提醒"入口（也可说"提醒"）：允许通知、逐项开关、查看"接下来会响的提醒"列表。通知权限被拒绝时会提示去系统设置开启。iOS 单 App 最多 64 条待发通知，当前上限约 30 条。

## 0.3.0 学习与手机效率

根据用户选择，不加入错题收集与复习。新增或整合以下入口，数据保存在本机：

| 功能 | 实现与范围 |
| --- | --- |
| 一句话生成清单 | 语音/文字分段、本机规则提取时间与用时；逐项核对名称、地图位置、日期与限制后追加到 Dayplan，最多8项。复杂自然语言尚需编辑，不是自由大模型理解。 |
| 计划随时调整 | 确认当前地点、重新开始时间和剩余用时，跳过已完成事项；保留其他固定时间、截止时间和当天最晚结束时间。只在明确勾选后解除所选任务的固定开始时间。 |
| 下一步助手 | 按已生成方案与用户确认的完成进度显示当前/下一任务；时间已过会提示重排，不会自行推断完成。方案会保存，重启可继续查看。 |
| 学习计时与进度 | 开始、暂停、继续、结束；切后台按经过时间计算。显示预计与实际用时，提供同名事项最近5次有效记录的平均用时参考，可删除历史。 |
| 截图变待办 | 在已索引照片的原文页提取草稿，确认后保留文字副本与照片标识；可回看来源。清除索引不会清除已保存任务中的文字副本。 |
| 个人资料问答 | 统一检索已授权索引照片、随口记录与所选课表，展示原文与来源。当前为文字匹配，不能完成任意语义推理。 |
| 出门准备清单 | 根据计划关键词、交通方式与所选课表建议物品；支持自行补充与按日期勾选。未读取天气，不会判断物品真的已携带。 |
| 每日简报 | 当前与下一步、今天剩余课程、计划截止事项、待整理记录；提示课表和计划的时间重叠。课表尚未自动成为排程硬限制。 |
| 随口收件箱 | 语音或文字快速记录，之后整理成任务或标记已整理；不读取微信/钉钉通知。 |

语音示例：“我今天要去图书馆做卷子两小时；然后18点吃饭30分钟”“现在做什么”“今天带什么”“暂停计时”“结束计时”“计划有变”。重排和清单导入会打开确认页面，不会仅凭模糊语音改动硬性限制。每日简报在 App 打开时更新，当前未新增后台推送或系统提醒。

本版不需要外部模型账号，不上传语音、截图或任务给大模型服务；Apple 系统语音、地图和用户允许的 iCloud 照片下载仍按既有设置使用。自然语言提取是可核对的本机规则草稿，尚不能替代完整的对话助手。手机运行与实际地图时间仍需用户确认。

## 0.2.0 Dayplan

新增本地日程清单：最多 8 件事，设置地点、用时、固定时间、最早开始、截止时间和必须先完成的事项。默认同时比较“少跑路”和“早点完成”，展示两种结果的通勤时长与结束时间，支持切换与分享。

首页打开 Dayplan，填写清单与出发地点后生成。语音“规划今天”可打开页面；目前需要在表单确认各项信息，尚不支持将整段自然语言自动解析为日程。睡觉、吃饭、休息请显式列入清单。未提供地点、时长或营业时间时，不会自动猜测。

步行、驾车、公交可请求 Apple 地图 ETA，按清单开始时间查询；不是随每段出发时间更新的实时导航。电动车按距离和预设速度粗估，地图失败也会回退粗估并标注。最优顺序仅相对于输入的时间限制和通勤矩阵，不代表实际路况的全局最优。地点搜索与路线请求会交给 Apple 地图处理。个人清单只保存于设备，公开仓库不包含用户日程。

## 没有 Mac 的构建方式

项目自带 `.github/workflows/ios-build.yml`，可在 GitHub 的 macOS runner 上生成 Xcode 项目、编译模拟器版本、归档设备版本并打包 `Cassie-unsigned.ipa`。该流程已成功运行。构建产物保留七天，过期后可重新运行工作流生成。

1. 将 **本目录的内容**放在一个 GitHub 仓库根目录。`project.yml`、`Sources/` 与 `.github/` 应在仓库根层。
2. 在该仓库的 Actions 页面运行 **Build Cassie for iOS**。普通网页上传可能遗漏点号开头的 `.github/` 目录；通过 Git 提交可避免这个问题。
3. 先查看编译结果；若失败，需根据日志修复。通过后下载 `Cassie-unsigned-build` artifact，解压得到待签名 IPA。
4. 在自己的 Windows 电脑中使用支持免费 Apple ID 的签名工具签名和安装。待签名 IPA 本身不能直接安装到 iPhone。

参考 [Sideloadly 官方说明](https://sideloadly.io/)：支持 Windows 与免费 Apple ID，免费签名有效期通常为七天，提供自动刷新；具体依赖与安装步骤以官方当前说明为准。Apple ID 登录在你自己的签名工具中完成，构建流程不需要 Apple ID 密码或签名证书。

免费签名、App Intents、中文离线语音和权限弹窗均需要在实际设备上验证。若设备没有当前可用的中文本地识别能力，App 会显示原因并保留文字输入，不会自动把录音上传。

## 有 Mac 时的本机构建

安装 Xcode 15 或更新版本及 XcodeGen：

```sh
brew install xcodegen
cd Cassie
xcodegen generate
open Cassie.xcodeproj
```

在 Xcode 中选择签名团队和独立的 Bundle ID，然后选择设备构建。`SWIFT_VERSION: 5.0` 表示 Swift 5 语言模式；本项目使用 Xcode 15+ 的工具链。

## 数据处理

- OCR 文字和备忘保存在 App 的 Application Support 目录，采用 iOS 完整文件保护并排除系统备份。
- 当前没有云端模型、分析统计或内容上传代码。授权 App 访问相册也不等于授权上传相册。
- 扫描默认只处理截图，可关闭该选项扫描全部照片。已索引内容均可搜索。
- iCloud 图片下载默认关闭；需要时由用户开启。索引不保存原图副本。
- 回到 App 时重新检查相册权限；已删除或移出授权范围的图片文字会从索引中移除。
- 扫描可暂停，下次跳过已处理且未修改的图片。暂停会等待当前图片读取或 OCR 返回。
- 清除索引只清除 Cassie 的本机索引，不删除照片。

## 接下来需要的真机检查

1. 麦克风与语音权限：允许、拒绝、撤销；录音中切后台、结束、再次录音。
2. 相册：有限和完整授权，新增/编辑/删除截图，撤销访问后的索引清理。
3. OCR：真实中英文截图、表格、小字和长截图；确认检索结果能对应原图。
4. 日历：选择“Celechron课表”、当前正在上的课、下一节课、跨天和无课情况。
5. 备忘：保存、重启 App 后恢复、删除。
6. 豆包：准确和错误的快捷指令名；台铃：用户取消确认、系统拒绝、车辆无连接。
7. 消息：取消、发送失败和系统报告已发送。送达状态仍以消息 App 为准。

源文件检查、云端 Xcode 模拟器编译、设备归档和 IPA 打包已通过；上述权限交互与真实功能仍需安装后检查。编译成功不代表已完成所有计划功能。
